Our summary

We set the plan for the final project: one team knowledge base from our
four Assignment 1 corpora, one routing API, five designs (T0 to T4) on
the same 50 held-out inputs, and the Canvas appendix layout from the
brief. We decided that the official codebook is the gold label, that
inputs which give away the answer must be cleaned, and that coordinates
must not enter the public corpus. We chose to retrain T4 on the Mac and
not on the shared CPU server.

We used the Cursor agent like a coding helper: merge and join scripts,
the team API wiring inside LLMBox, the experiment runner and scorer,
the LoRA training loop, the appendix packaging script, debugging, and
code completion while we edited Python and shell. All graded model calls
use local Phi-4-mini weights. No hosted LLM was called in any team
experiment. We read the outputs, checked numbers against metrics.json,
and rescored after every code change.

  member memo PDFs, memo/member_summaries.md, docs/project_facts.md,
  and team chat handover text.
